At every step of ARC-AGI-3, the environment provides an agent with an observation. This contains the visual state of the environment
alongside information about the game's status, progress through its levels, and available actions.

## Game Frames

The main part of an observation is one or more game frames: 2D grids of colored cells, with each color represented by an index number from the official palette.

### Frame Grid Structure

- **Dimensions:** 64⨯64
- **Cell Values:** Integer values 0-15 representing colors from the palette above.
- **Coordinate System:** (0, 0) at the top-left, with x increasing to the right and y increasing downward.

### Multi-frame Animations

An action can produce a single frame or an animation, such as an object sliding across the grid.
The observation includes the frames from that action in chronological order, before the agent chooses its next action:

- **Instant actions:** Produce a single frame showing the result.
- **Animation-triggering actions:** Produce a sequence of frames showing the transition.

<Tip>
For simplicity, many agents only use the newest frame and discard the intermediate ones.
However, if your agent can make use of seeing the animation - feel free to process all frames.
</Tip>

## Additional Metadata
Alongside the frames, each observation includes information about the game's status, progress, and available actions.

### Game State
At every step, a game is in one of four states:

| State | Description |
|---|---|
| `NOT_PLAYED`    | No game has been started |
| `NOT_FINISHED`  | The game is active and awaiting another action |
| `WIN`           | All required levels were completed successfully |
| `GAME_OVER`     | The run ended without a win |

### Level & Progress

Because each environment has multiple levels, the environment informs the agent at every step how many levels
it has completed and how many are required to win the game.

| Information | Description |
|---|---|
| Levels completed        | How many levels the agent has solved in the current run, starting at zero. |
| Levels required to win  | How many levels the agent must complete to win the game. |

Each time the agent clears a level, the number of completed levels increases. Once it has completed all required levels,
the game state changes to `WIN`.

### Available Actions (Action Space)
Each observation also includes a list of available actions.

<Note>This list is constant for each game; it does not indicate which actions advance the game at the moment.
For example, a movement action remains available even when a wall blocks movement, and attempting it still counts as an action.</Note>

Depending on the game, these actions might include up, down, left and right movements, special actions, a mouse click, and even an undo action.
All actions are described in greater detail in the [Action Space](/theory/action-space) page.
